No developer certificate needed

Install in three steps.

The release is signed but not Apple-notarized. You do not need an Apple Developer account or your own certificate.

Get GitLab Alert 0.1.3
1
Download and move

Open the DMG and drag GitLabAlert.app onto the Applications shortcut.

2
Approve it in macOS

Try opening the app, then use System Settings → Privacy & Security → Open Anyway. If macOS still blocks it, run xattr -dr com.apple.quarantine "/Applications/GitLabAlert.app" once in Terminal.

3
Connect GitLab

Choose your GitLab origin and save a personal access token with only read_api.

Why the command? The release uses a stable self-signed identity, not Apple Developer ID notarization. The targeted command removes only the downloaded-file quarantine flag; xattr -cr removes every extended attribute and is broader than necessary.

Your token stays on your Mac.

Credentials live in the macOS Keychain. GitLab Alert asks only for read_api and sends the token only to the GitLab origin you configure.
